# Contributing

Contributions are welcome. Please open an issue before a large change, and describe how you tested code that depends on PS5 hardware.

By submitting a contribution, you confirm that you have the right to submit it under this project's GPL-3.0-only license. Preserve existing copyright and third-party notices. Add a short provenance and license note to [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) if you adapt code or include assets from another project.

Run `make HOST=1 test` for protocol changes. A PS5 build requires the pinned `ps5-payload-sdk` version described in [README.md](README.md).
